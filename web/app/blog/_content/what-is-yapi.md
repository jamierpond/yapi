# What is yapi?

Yapi is an API client that runs from the terminal. It's configured using markdown files and covers the core affordances of Postman, Bruno and Insomnia, or the Visual Studio Code HTTP plugin.

```yaml
yapi: v1
url: https://api.github.com/repos/yapi
method: GET
```

## Why make another API client?
Well it started just from me chaining a few CLI tools together with bash.
