## yapi send

Send a quick request without a config file

### Synopsis

Send a one-off HTTP or TCP request directly from the command line.
The transport is auto-detected from the URL scheme (tcp://, grpc://, or HTTP by default).

Examples:
  yapi send https://httpbin.org/get
  yapi send -X POST https://httpbin.org/post '{"hello":"world"}'
  yapi send tcp://localhost:9877 '{"type":"health","params":{}}'
